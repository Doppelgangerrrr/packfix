# Зеркала ресурспака для PackFix

Здесь лежит `packfix.json` — список «какой ресурспак где скачать». Мод
[PackFix](https://t.me/AstrumMCHelp) читает его, когда сервер не смог отдать ресурспак, и берёт
файл по ссылке отсюда.

## Как обновить, когда сервер поменял пак

1. Узнать sha1 нового пака. Проще всего — у себя: зайти на сервер, дождаться загрузки пака и
   посмотреть последнюю строку в `.minecraft/downloads/log.json`, поле `hash`. Сам файл лежит
   рядом: `.minecraft/downloads/<id>/<sha1>`, без расширения.
2. Залить этот файл куда-нибудь с прямой ссылкой (релиз в этом же репозитории — самый надёжный
   вариант: Releases → Draft a new release → перетащить файл → Publish).
3. Дописать сюда пару «хеш: ссылки»:

```json
{
  "updated": "2026-11-01",
  "packs": {
    "6861225b94d1dff14401e967d9fce5e703b25153": ["https://kappa.lol/abNVdE"],
    "НОВЫЙ_SHA1_СЮДА": ["https://github.com/ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ/releases/download/rp/pack.zip"]
  }
}
```

Старые записи можно оставлять: у кого-то ещё может стоять прошлая версия пака.

Новая версия мода при этом не нужна — он читает этот файл каждые 10 минут.

## Почему это безопасно

Мод сверяет sha1 скачанного файла с тем, который требует сервер. Если в манифесте окажется
ссылка не на тот файл — мод просто откажется его ставить. Подсунуть игрокам чужой пак через этот
список нельзя.
